# 小鹅通课程页布局重构

一个 Tampermonkey 用户脚本：把小鹅通 PC 课程播放页改成更清爽的 16:9 布局，默认网页宽屏，支持选集、无刷新切课和播放参数记忆。

## 功能

- **清爽布局**：播放器限制为最大 1200px 的 16:9，隐藏详情、评论、课程互动、右侧推荐等干扰区域，保留导航和页脚。
- **默认网页宽屏**：首次进入播放页自动进入网页宽屏；按 `F` 或控制条按钮可以回到普通窗口。
- **切换保留宽屏状态**：切换课时前是网页宽屏，切换后继续网页宽屏；原来是普通窗口就保持普通。
- **全屏切换**：支持普通窗口、网页宽屏、原生全屏；双击视频可进出网页宽屏。
- **选集面板**：悬停控制条「选集」展开目录；多系列课程在顶部用 tab 切换；支持章节折叠、当前课定位和课时搜索。
- **进度统计**：每个章节右侧显示总课时数，以及已学完、学习中数量。
- **无刷新切课**：点击课时、站内「下一节」、连续播放和浏览器前进/后退都不整页刷新；失败时自动回退为普通跳转。
- **播放参数记忆**：记住音量、静音、倍速和播放形式，刷新或切课后自动恢复。
- 只在课程视频播放页生效，不影响课程列表等其他页面。

## 安装

先安装 [Tampermonkey](https://www.tampermonkey.net/)，再选择一种安装方式。

### 从 Greasy Fork 安装（推荐）

<https://greasyfork.org/zh-CN/scripts/565101>

从 Greasy Fork 安装后，脚本更新也走 Greasy Fork，Tampermonkey 会定期检查。

### 从 GitHub 安装

```text
https://raw.githubusercontent.com/StreetCornelia/xet-plus/refs/heads/main/xet-course-layout.user.js
```

打开上面的 raw 链接即可安装。这种方式跟随 GitHub 更新，不经过 Greasy Fork。

## 使用

1. 打开小鹅通 PC 课程视频页（`/p/t_pc/course_pc_detail/video/...`）。
2. 播放器就绪后会自动进入网页宽屏；按 `F` 或点击控制条的网页宽屏按钮回到普通窗口。
3. 鼠标移到控制条「选集」按钮上展开目录，点击课时即可无刷新切换。
4. 多系列课程在选集面板顶部切换 tab；搜索只作用于当前 tab。
5. 音量、倍速和播放形式会自动保存，下次进入课程或切换课时后恢复。

## 更新

- Tampermonkey 默认约每 24 小时检查一次更新。
- 想立即检查：Tampermonkey 管理面板 →「实用工具」→「检查脚本更新」，或对单个脚本点「检查更新」。
- 如果版本一直不变，确认脚本是从 Greasy Fork 安装的；必要时从脚本页重新安装。
- 只从 GitHub raw 安装的脚本不会经过 Greasy Fork 更新。

## 常见问题

**选集面板显示加载失败？**

课程目录需要登录状态。请先登录小鹅通，再点击面板里的「重试」。

**没有自动进入网页宽屏？**

站点播放器没有提供网页宽屏按钮时会跳过自动宽屏。可以按 `F` 或使用控制条上的按钮。

**切换课时后回到了普通窗口？**

脚本会保留切换前的状态。如果切换前是普通窗口，切换后就保持普通；需要宽屏时按 `F` 即可。

**切换课时还是整页刷新了？**

站点的播放器接口不可用或初始化超时时，脚本会自动回退为整页跳转。稍后重试或刷新页面即可。

**会影响课程列表页吗？**

不会。脚本只匹配课程视频播放页 `/p/t_pc/course_pc_detail/video/*`。

## 隐私

- 不向任何第三方上传数据。
- 课程目录只请求当前小鹅通站点的同源接口，使用浏览器里已有的登录状态。
- 播放偏好和目录缓存只保存在本站的浏览器存储中。
- 脚本不包含账号、token 或密钥。

## 兼容性

- 适用于所有小鹅通 PC 租户的课程视频播放页。
- 直播回放使用站点返回的链接，在新标签打开。
- 原生全屏由浏览器控制，切换课时后不会自动恢复；网页宽屏会保留。
